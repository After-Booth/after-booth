The current authenticated English-output AI flow is verified by automated replay through HANDED_OVER and statistics, including both last-item race branches. This does not establish video capture, a manual judging run or English speech. See [ENGLISH_REPLAY](ENGLISH_REPLAY.md) for exact inputs and evidence. No new live/record call is authorized by this document.

Use two synthetic verified members in separate HTTPS browser contexts: a giver owns the event and inventory; a receiver owns the pickup request and reservation. All displayed times use Asia/Seoul (KST). Keep credentials, email addresses, codes, cookies and tokens out of the recording.
